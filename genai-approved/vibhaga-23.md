G23-001: अहम् ______________ पठामि, अहम् ______________ लिखामि। (द्वयोः रिक्तस्थानयोः पूरणम्)
विकल्पाः: न / एव, तु / अपि, अपि / न, एव / आम्
Answer: तु / अपि
Status: Confirmed
Source-Section: विभागः 23
Approved: 2026-09-20
Note: A picture hint doesn't apply to अव्यय (indeclinables express logical relations, not visible objects). Of the five अव्यय-पदानि (एव, न, तु, अपि, आम्), न and आम् don't fit either blank grammatically. "तु ... अपि" (however ... also) is the standard idiomatic pairing here. The pair is written "तु / अपि" (slash, not comma) so it parses as a single MCQ option.
